    Code-Check zur Black Week

    Einmalig einrichten. Der Check läuft auf GitHub. Damit der Button ihn starten darf, braucht er einen GitHub-Token. Er wird nur auf diesem Gerät gespeichert.

    1. Neuen Token anlegen (Fine-grained).
    2. Bei Repository access nur my-project-26/SportSupp wählen.
    3. Bei Permissions Actions: Read and write und Contents: Read-only setzen.
    4. Token kopieren und hier einfügen.
